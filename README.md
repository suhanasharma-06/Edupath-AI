# 🎓 EduPath AI

EduPath AI is an AI-based college recommendation chatbot that helps students find the best colleges based on their preferences like location, fees, and placement.

## 🚀 Features
- College recommendation system
- Database integration using MySQL
- Campus tour videos
- College images and details
- Placement & hostel information

## 🛠️ Technologies Used
- Python (Flask)
- MySQL
- HTML, CSS, JavaScript

## 📂 Project Structure
- app.py → Backend logic
- templates/ → HTML pages
- static/ → CSS & images
- database.sql → Database schema

## ⚙️ How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000
